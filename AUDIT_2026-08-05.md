### A. Autentifikatsiya

**TC-A01 — Telefon formati**
Qadamlar: `/login` → raqam kiriting → Davom eting.
Kutilgan: faqat `998XXXXXXXXX` (12 raqam) qabul qilinadi (`AuthContext.jsx:518`).
Chegara: `+998 90 123 45 6` (11 raqam) → rad; `77 123 45 67` (998 emas) → rad; `+9989012345678` (13) → rad; bo'shliq/qavs/tire → `replace(/\D/g,'')` tozalaydi → qabul; `+++998901234567` → tozalanadi → **qabul (tekshirish kerak: UI xohlanmagan belgini ko'rsatadimi)**.

**TC-A02 — Parol siyosati (ro'yxatdan o'tish)**
Kutilgan: <6 belgi rad; qora ro'yxat (`parol123`, `password`, `admin`…) rad; `abcd`/`1234` ketma-ketligi rad; `aaaa` takrori rad.
Chegara: `aaaaaa` → `hasRepeatedChars` rad ✅; `Parol123` (bosh harf) → qora ro'yxat `toLowerCase()` bilan tekshiradi → **rad**; 100+ belgili parol → Firebase qabul qiladi; emoji/kirill parol → qabul.
⚠️ **Muhim:** `validatePassword` FAQAT `isRegistering=true` da chaqiriladi. Login'da tekshiruv yo'q (to'g'ri qaror), lekin eski, kuchsiz parolli hisoblar hech qachon majburiy yangilanmaydi.

**TC-A03 — Brute-force bloklash**
Qadamlar: bir xil raqamga 5 marta noto'g'ri parol → 6-urinish.
Kutilgan (UI): "akkaunt 15 daqiqaga bloklandi".
**Chegara (buzadi):** DevTools → `localStorage.removeItem('iqro_login_attempts')` → bloklash yo'qoladi. Incognito, boshqa brauzer, yoki to'g'ridan-to'g'ri Firebase Auth REST API → bloklash umuman qo'llanmaydi. → **12-band**

**TC-A04 — Ro'yxatdan o'tish yarim yo'lda uzilishi**
