# Toifa Pro — Kasbiy Sertifikatlash Tayyorgarligi Platformasi

Toifa Pro — CHQBT (Harbiy ta'lim) va Tasviriy san'at fanlaridan o'qituvchilar attestatsiyasi, kasbiy sertifikatlash va bilimini sinash uchun mo'ljallangan zamonaviy, premium dizaynga ega web-platforma.

## 🚀 Imkoniyatlar
- **Ikki xil yo'nalish:** CHQBT va Tasviriy san'at yo'nalishlari o'rtasida oson almashish.
- **Turli rejimlar:**
  - 📖 **Takrorlash (Practice):** Savollarni izohlari va mnemonik kalit so'zlari bilan o'rganish.
  - ⚡ **Flashcards:** Bilimlarni tezkor kartochkalar orqali mustahkamlash.
  - 🏆 **Imtihon (Exam):** Vaqt bilan chegaralangan real imtihon simulyatsiyasi.
- **Smart Progress:** Har bir mavzu bo'yicha o'zlashtirish ko'rsatkichlarini kuzatib borish.
- **Anti-Cheat:** Imtihon vaqtida boshqa sahifaga o'tishni cheklovchi xavfsizlik tizimi.
- **Mobil Optimallashgan:** Istalgan qurilmadan (telefon, planshet) qulay foydalanish.

## 🛠 Texnologiyalar
- **Core:** React.js + Vite
- **Styling:** Vanilla CSS (Custom UI Design)
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Hosting:** Vercel (Tavsiya etiladi)

## 📦 O'rnatish va ishga tushirish
1. Repozitoriyani yuklab oling:
   ```bash
   git clone https://github.com/USER_NAME/toifapro.git
   ```
2. Loyiha papkasiga kiring:
   ```bash
   cd toifapro
   ```
3. Kerakli kutubxonalarni o'rnating:
   ```bash
   npm install
   ```
4. Loyihani ishga tushiring:
   ```bash
   npm run dev
   ```
